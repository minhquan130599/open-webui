# Ảnh Telegram còn thiếu trong trung tâm trợ giúp (cập nhật 27/11/2026)

Các bước dưới đây đang để trống ảnh vì cần chụp trong ứng dụng Telegram. Chụp xong, đặt đúng tên file vào
`static/help-center/images/` rồi thêm `image` + `caption` cho bước tương ứng trong `static/help-center/articles.json`.

Ảnh cũ (bot bản trước: hỏi AI, nhận báo cáo qua Telegram) đã sao lưu ở `docs/help-center/anh-cu-telegram/`.

Bài "Liên kết Telegram với tài khoản" đã đủ ảnh.

## Bài "Gửi tin nhắn vào kênh từ Telegram" (`telegram_chat`)

| Bước | Ảnh cần chụp | Tên file |
|---|---|---|
| Bot chỉ chuyển tin nhắn vào kênh | Gõ một tin khi chưa chọn kênh: bot nhắc chọn kênh trước | `tgc-t9-chua-chon-kenh.png` |
| Gửi file hoặc ảnh | Gửi một file kèm chú thích và bot báo đã gửi | `tgc-t7-gui-file.png` |
| Cài đặt, hủy liên kết | Menu ⚙️ Cài đặt của bot (tài khoản, kênh đang gửi, các nút) | `tgc-t8-cai-dat.png` |
